# COMP3000 - Final Year Project - Spoonymyalgia
Spoonymyalgia is a symptom tracker and monitor specifically designed for Fibromyalgia.

To use the application, download the main branch, and extract into a folder.

Once open in VS Code, make sure you download all the libraries in requirements.txt.

Then either run the program through the Run and Debug interface or type 'flask run' into the CLI.

Once running, create a new account and you will have access to all the features
